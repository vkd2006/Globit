# Globit — Global Remote Employee Equipment Logistics

Globit is a web-based prototype designed to simplify equipment logistics for remote employees worldwide. It helps manage employee information, laptop procurement requests, asset tracking, shipments, and equipment returns during offboarding.

## Features

- **Employee Management:** Add and manage remote employee details.
- **Laptop Procurement:** Create laptop requests and approve or reject them.
- **Asset Tracking:** Track equipment allocation and return status.
- **Shipment Tracking:** Update shipment status, carrier details, and tracking numbers.
- **Offboarding:** Manage equipment returns and inspection status.
- **Responsive Interface:** A clean interface with light and dark theme support.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/vkd2006/globit.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies are required for the current prototype.

## Current Status

Globit is currently a frontend prototype. It stores data in browser Local Storage, so data is not shared between users or devices.
